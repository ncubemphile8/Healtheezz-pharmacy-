# Healtheezz Pharmacy website

Premium, responsive pharmacy retail website concept inspired by the Booties Pharmacy mobile shopping experience, with an original Healtheezz visual direction.

## Included
- Cinematic video-led hero with poster/fallback image
- Responsive navigation, search and mobile bottom navigation
- Category discovery cards and promotional campaign panels
- Sample product catalogue with category filters and live search
- Quick-view product modal, add-to-basket interactions and toast feedback
- Scroll reveal, hover motion, floating WhatsApp action
- Business address and public contact details currently listed for Healtheezz Pharmacy

## Important launch notes
- The current brand mark is a temporary typographic placeholder. Replace it with the pharmacy's supplied official logo and confirm the approved brand colours.
- Product names, images and prices are illustrative demo content. Replace them with approved inventory and pricing before launch.
- Confirm the telephone/WhatsApp number and opening hours with the pharmacy before publishing.
- The basket is a front-end demonstration only; it is not connected to payment, inventory or an order-management system.
- Replace the remote hero video with an approved, compressed pharmacy/wellness video asset if the current stock video is not suitable. The hero includes a poster fallback.
- No prescription ordering or medical advice functionality is enabled.

## Deploy
This is a static site. Import the repository into Vercel with the default settings; no build command is required and the output directory is the repository root.
